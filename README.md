# Yoko

Yoko is an open-source, low-cost AI agent system for freelance developers.
Give it a client brief and it helps with the repeat work: scoping the task,
designing the layout, writing code, deploying the site, and preparing the handoff.

Built with the Claude API.

## Features
- Turns a short client brief into a scope and task list
- Generates website and app code
- Deploys to Vercel, Netlify or GitHub Pages
- Designed to keep API costs low for solo developers

## Status
Early-stage and under active development. Feedback and contributions are welcome.
